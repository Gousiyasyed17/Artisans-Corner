# Artisan's Corner

## Overview
Artisan's Corner is a Multi-Vendor Marketplace where artisans can sell handmade products and customers can browse, purchase, review, and manage orders.

## Features
- Buyer, Seller & Admin Login
- Product Management (CRUD)
- Cloudinary Image Upload
- Shopping Cart
- Wishlist
- Buy Now
- Coupon System
- Razorpay Payment
- Order Management
- Invoice Generation
- Cancel Order
- Return Request
- Reviews & Ratings
- Seller Dashboard
- Inventory Management
- Sales History
- Commission Calculation

## Tech Stack
### Frontend
- React.js
- Vite
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

### Services
- Cloudinary
- Razorpay

## Installation

### Backend
```bash
npm install
npm run dev
```

### Frontend
```bash
npm install
npm run dev
```

## Environment Variables

RAZORPAY_KEY_SECRET=

Frontend:
